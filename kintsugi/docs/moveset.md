# ท่าทั้งหมดใน Kintsugi Run

ไฟล์ข้อมูลท่าตัวจริงอยู่ที่ `game/js/moves.js` (`MOVES` และ `ATTACKS`) หน้านี้อธิบายว่าแต่ละท่ามาจากไหนและสร้างอย่างไร

## ที่มาของท่า

ชุด sample ที่มีไฟล์งานจริงให้มาแค่ 3 แอนิเมชัน:

| แอนิเมชัน | ไฟล์ | เฟรม | จังหวะ |
| :--- | :--- | :---: | :---: |
| Idle | `assets/sprites/idle.aseprite` | 10 | 60 ms |
| From idle (ออกตัว) | `assets/sprites/walk.aseprite` tag `from idle` | 2 | 50 ms |
| Walk cycle | `assets/sprites/walk.aseprite` tag `walk cylcle` | 24 | 50 ms |

ท่าอื่นทั้งหมดของชุดเต็มมีแค่เป็น GIF ตัวอย่างใน `assets/reference/gifs/` ซึ่งติดลายน้ำ "PREVIEW" หรือมีพื้นหลังและถูกขยายขนาด เกมจึง**ไม่ดึงพิกเซลจาก GIF พวกนี้** แต่ใช้ GIF วิเคราะห์ท่าทางและจังหวะ แล้วสร้างท่าใหม่จาก 3 อย่าง:

1. **เฟรมจริง** idle/walk เลือกเฟรมที่ท่าทางใกล้เคียง (เช่น walk เฟรม 0 = ยกเข่า, เฟรม 3 = ก้าวยาว, เฟรม 10 = ขาเหยียด)
2. **Transform** เอียงตัว (rot), ยืด/หด (squash & stretch), หมุนทั้งตัว (spin), เลื่อนตำแหน่ง และแฟลชขาว
3. **VFX แยกเลเยอร์** วงดาบรูปเสี้ยวจันทร์, เส้นแทง, คลื่นกระแทก, ลำแสง, เงาตามหลัง และฝุ่น ตามที่คู่มือดีไซน์ (§1 ข้อ 4) กำหนดให้แยก Body กับ VFX

ถ้าได้ชุดเต็มมา ให้วางไฟล์ `.aseprite` ใน `assets/sprites/` เพิ่มชื่อท่าใน `ANIMATIONS` ของ `tools/build_sprites.py` แล้วรันใหม่ จากนั้นเปลี่ยน `pose()` ใน `game/js/player.js` ให้ใช้แอนิเมชันจริงแทน transform ส่วน VFX ใช้ต่อได้เลย

## ทดสอบ

เปิด `game/index.html?debug` แล้วรันใน console:

```js
await PT.runAll()
```

บอทจะกดปุ่มจริงผ่าน input layer และเดินเกมทีละเฟรม เพื่อตรวจคอมโบ 3/5 จังหวะ อุโมงค์ (หมอบ/สไลด์) บันได ปล่องถีบกำแพง และเหวกว้างของทั้ง 2 ด่าน
