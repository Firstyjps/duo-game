## 5) ข้อควรระวัง (บทเรียนจาก session นี้)
- **ไฟล์ชนกัน**: มีคนอื่น (session อื่น/Antigravity) เคยย้ายโฟลเดอร์ `game/` ไปถังขยะ, kill preview server, แก้ launch.json, publish ทับ artifact — ให้มีเจ้าของ repo คนเดียว และเช็ค `git log`/mtime ก่อนแก้
- สไปรต์ทุกไฟล์ **หันซ้าย** → mirror เมื่อหันขวา
- Three.js: `texture.clone()` ก่อนภาพโหลดเสร็จ = ไม่มีภาพ (สไปรต์หาย) · FogExp2 กับกล้อง ortho ระยะไกลทำให้มืดทั้งจอ
- Preview cache: ใช้ `fetch(url,{cache:'reload'})` + เปลี่ยน query ไม่งั้นได้ไฟล์เก่า · ทดสอบผ่าน `?debug` → `__step(ms)` / `__dbg()` (Browser pane ซ่อนอยู่ rAF หยุด)
- PixelLab: animate_image จาก idle มักหันกลับด้านกลางท่า → ต้อง mirror ทีละเฟรม (ดู FLIP ใน build_atk.py) · create_character v3 ต้องการภาพ **หน้าตรง** เป็น south
- ⚠️ user เผลอแชร์ภาพที่เห็น PixelLab Secret → แนะนำให้ regenerate ในหน้า Account แล้ว
- user ไม่ชอบการหมุนตัวเป็นวงกลม (ห้ามใส่ท่าหมุนทั้งตัว)
